Modèles et galerie

Chaque modèle est un projet complet créé avec burrow new -template <nom>. Ils contiennent données, niveaux, documents d'interface et un script ; aucune logique de jeu n'est dans le moteur.

Les descriptions des modèles sont en anglais.

platformer

A 2.5D platformer built only from engine features: a side-scroller camera, two hand-built levels (levels/.level) with checkpoints and a goal, kinematic moving platforms (physics3d), coins, hazards, a kill plane, a HUD, a pause menu, quick save and load, particles and sounds. All game rules are in one Go script (script…

burrow new mygame -template platformer

builder

A creative builder on a flat world. Press 1-4 to stamp a tower, wall, pyramid or house in front of the start position (the architect script, scripts/architect/main.go). Left/right click break and place blocks by hand; Ctrl+Z / Ctrl+Shift+Z undo and redo.

burrow new mygame -template builder

empty

An empty project on a flat world. Put assets in assets/, scenes in scenes/ and describe the game in vox.project (see docs/getting-started.md in the Burrow repository).

burrow new mygame -template empty

gogame

A Go game: the logic is a plain Go main package (main.go) that imports burrow-engine/gogame, with full engine access. Scenes, prefabs, input and assets in this folder load as in any Burrow project.

burrow new mygame -template gogame

lobby_match

A multiplayer lobby and match starter. Players connect to a lobby (team, colour, ready), the host picks the map and the time limit and starts, a countdown runs, the chosen map loads, the first avatar to reach the golden pad in the middle wins, and everybody comes back to the lobby with the results.

burrow new mygame -template lobby_match

models

Shows the three asset kinds a scene can reference, all resolved through the asset registry (also from a packed game):

burrow new mygame -template models

multiplayer

A multiplayer-ready starter: a flat world, the first-person controller (its camera and movement stay local even in a session), and one WebAssembly script, avatars, that draws and moves one avatar per connected player from that player's input in the server's player registry.

burrow new mygame -template multiplayer

sandbox

A voxel sandbox: streamed terrain, a first-person controller and the HUD.

burrow new mygame -template sandbox

scripted

Three WebAssembly scripts written in Go run inside the deterministic simulation: spin turns a cube, painter lays a line of wood blocks, wander strolls over the terrain using raycasts and the simulation RNG. Sources live in scripts/name/main.go; compiled modules in assets/scripts/.

burrow new mygame -template scripted
