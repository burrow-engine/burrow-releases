Jouez en deux minutes

Du téléchargement à un jeu qui tourne, puis à une version autonome.

  1. Étape 1

    Télécharger le Hub

    Téléchargez le Hub pour votre système. C'est le seul téléchargement : il installe le moteur et les modèles pour vous.

    Télécharger le Hub, puis lancez l'installateur ou décompressez-le et lancez le Hub

    Télécharger le Hub

  2. Étape 2

    Créer un projet depuis un modèle

    Choisissez un modèle et appuyez sur le bouton pour créer votre projet. Le modèle Sandbox est le moyen le plus rapide de jouer.

    Projects, puis New project, puis choisir un modèle

    Détails : le guide du Hub.

  3. Étape 3

    Appuyer sur Play, puis compiler

    Ouvrez le projet dans l'éditeur et appuyez sur Jouer. Quand il vous plaît, construisez un jeu autonome.

    burrow build -o mygame

    Détails : exporter un jeu.

Plutôt du code ?

Créez le projet en ligne de commande et écrivez votre gameplay dans un court script Go. Les scripts se compilent en WebAssembly avec burrow script build.

burrow new mygame -template platformer
cd mygame
burrow edit
burrowsdk.Register(burrowsdk.Script{
	OnTick: func(self burrowsdk.Entity, dt float64) {
		t, _ := burrowsdk.GetTransform(self)
		t.Rot[1] += 90 * float32(dt) // spin
		burrowsdk.SetTransform(self, t)
	}})

scripts/spin/main.go : fait tourner l'objet auquel le script est attaché.

Bon à savoir

  • Burrow est jeune et l'API est en v0 : elle peut changer d'une version à l'autre.
  • Le Hub demande avant de chercher des mises à jour. Tant que vous n'avez pas dit oui, il ne contacte rien.
  • Les installateurs ne sont pas encore signés. La page de téléchargement explique le premier lancement sur votre système.
