Télécharger le Hub

Un seul téléchargement pour votre système : le Burrow Hub. Il installe pour vous le moteur, les modèles et le bac à sable.

Version préliminaire (v0.4). Détails par plateforme et limites connues : Plateformes (en anglais).

Choisissez votre système

Un téléchargement par système : le Hub Burrow. Il installe pour vous le moteur, les modèles et le Sandbox. Vous pouvez vérifier la somme SHA-256 si vous le souhaitez.

Windows Votre système

Demande Windows 10 1809 ou plus récent et un pilote Vulkan 1.3, fourni par votre pilote graphique.

Les sommes des installateurs viennent du fichier SHA256SUMS joint à la version ; celle du zip portable du Hub vient du manifeste signé.

Et ensuite

  1. Installez le Hub, ou décompressez le zip portable. Il est petit et prépare votre dossier de projets.
  2. Choisissez un modèle et appuyez sur Use this template. Le modèle Sandbox est le moyen le plus rapide de jouer.
  3. Le Hub installe le moteur après votre accord pour chercher des mises à jour.

Premier lancement

Les installateurs ne sont pas encore signés : votre système demande une confirmation la première fois. Ces conseils vous aident à la passer.

Windows SmartScreen

  • Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  • Windows Defender peut signaler un programme récent et non signé comme une menace (détection générique en !ml). Vérifiez la somme SHA-256 de cette page, puis restaurez le fichier depuis Historique de protection ou ajoutez une exclusion pour le dossier Burrow.

macOS Gatekeeper

  • Si le premier lancement est bloqué, ouvrez Réglages Système, Confidentialité et sécurité, descendez et cliquez sur Ouvrir quand même à côté du message Burrow.
  • Sur macOS 14 et plus ancien, vous pouvez à la place faire un clic droit sur Burrow dans Applications, choisir Ouvrir, puis Ouvrir.
  • Ou depuis le Terminal : xattr -dr com.apple.quarantine /Applications/Burrow.app.

Linux AppImage

  • Rendez l'AppImage exécutable avec chmod +x Burrow-*.AppImage, puis lancez-la.
  • Elle demande FUSE 2 (sudo apt install libfuse2 sur Ubuntu 22.04 et plus récent). Sans FUSE, lancez-la avec --appimage-extract-and-run.
  • Il faut aussi un pilote Vulkan : sur Debian ou Ubuntu sudo apt install libvulkan1 mesa-vulkan-drivers.

Vérifier un téléchargement

Comparez la somme SHA-256 du fichier avec celle affichée sur sa carte :

# Windows (PowerShell or cmd)
certutil -hashfile <file> SHA256
# macOS / Linux
shasum -a 256 <file>

La liste des fichiers est elle-même signée : manifest.json porte une signature Ed25519 et le Hub la vérifie avec la clé de publication compilée en lui avant de télécharger quoi que ce soit. La clé ne change jamais en silence : une nouvelle clé est livrée à côté de l'ancienne pendant une version.

Le kit moteur contient burrowrelease et la clé publique burrow-release.pub : vérifiez un manifeste avec burrowrelease verify (hors ligne, sans les sources).
