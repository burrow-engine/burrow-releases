Is Burrow for you?

What works today and what does not.

A good fit

  • Voxel games of any genreThe engine assumes no game. Templates cover a platformer, a puzzle, a strategy game and survival.
  • Replays and testsThe simulation is fixed-step: same seed and inputs give the same state hash on x86-64 and ARM64. Verified on macOS Apple silicon and macOS Intel (x86-64 binary under Rosetta on Apple silicon). Sessions replay and verify without a window.
  • Creatures and AIWalkers, swimmers, climbers and flyers find paths around the world. Behaviour trees and perception drive them, and scripts can read and write what they remember.
  • Go or visual scriptingScripts are Go compiled to WebAssembly, sandboxed and metered. Visual graphs are there if you would rather not write code.
  • AutomationThe command line covers the whole project workflow, and an MCP server lets a tool script the editor.
  • Windows, macOS and LinuxBurrow runs on desktop Vulkan. The Platforms page says what has been tested where.

Not there yet

  • Online multiplayerMultiplayer arrived in 0.2: deterministic lockstep over TCP, 16 players by default. It is new and has not been tried at scale on the internet.
  • Mobile and webBurrow targets desktop Vulkan. Mobile and web are not supported.
  • ConsolesNo console support, and none planned for now.
  • Very large open worldsTerrain streams in chunks. Generation was tested up to a radius of 12 chunks, not at huge open-world scale.
  • A stable v1 APIThe API is v0 and may change between releases.
  • Some platforms are newThe Windows, Linux and macOS Intel builds are recent. The Platforms page lists what has been tested where.

Also missing

  • A published Go moduleThe engine is not available as a Go module yet.
  • Ready-made creaturesNavigation, perception and behaviour trees exist. Health, damage and loot are scripts you write; the survival template shows one way.
  • Water that floods the worldWater keeps its volume, but a source reaches a few blocks and a breach farther. It does not yet flow toward holes.
  • A minimap or selection rectangleThese widgets are not built yet. Selected units are tinted instead.
  • Collision events in scriptsScripts poll for overlaps. Engine events are not passed to them.
  • A configurable day lengthA day is a fixed 24000 ticks.
  • French documentationThe docs are in English for now.

Not sure?

Try the Sandbox. Install the Hub, create a project from the Sandbox template and press Play. It shows what the engine does.
