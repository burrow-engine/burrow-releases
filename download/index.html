Installer sums come from the SHA256SUMS file attached to the release; the portable Hub zip sum comes from the signed manifest.

What happens next

  1. Install the Hub, or unzip the portable zip. It is small and sets up your projects folder.
  2. Pick a template and press Use this template. The Sandbox template is the quickest way to play.
  3. The Hub installs the engine after you agree to check for updates.

First launch

The installers are not signed yet, so your system asks for a confirmation the first time. These tips get you through it.

Windows SmartScreen

  • Windows may say "Windows protected your PC": click More info, then Run anyway.
  • Silent install: BurrowSetup-X.Y.Z-x64.exe /S. Your projects are never touched by the uninstaller.
  • Windows Defender may flag a new, unsigned program as a threat (a generic !ml detection). Check the SHA-256 on this page, then restore the file from Protection history or add an exclusion for the Burrow folder.

macOS Gatekeeper

  • If the first launch is blocked, open System Settings, Privacy and Security, scroll down and click Open Anyway next to the Burrow message.
  • On macOS 14 and older you can instead right click Burrow in Applications, choose Open, then Open.
  • Or from Terminal: xattr -dr com.apple.quarantine /Applications/Burrow.app.

Linux AppImage

  • Make the AppImage executable with chmod +x Burrow-*.AppImage, then run it.
  • It needs FUSE 2 (sudo apt install libfuse2 on Ubuntu 22.04 and newer). Without FUSE run it with --appimage-extract-and-run.
  • You also need a Vulkan driver: on Debian or Ubuntu sudo apt install libvulkan1 mesa-vulkan-drivers.

Verify a download

Compare the SHA-256 sum of the file with the one shown on its card:

# Windows (PowerShell or cmd)
certutil -hashfile <file> SHA256
# macOS / Linux
shasum -a 256 <file>

The list of files is itself signed: manifest.json carries an Ed25519 signature, and the Burrow Hub checks it against the release key compiled into it before it downloads anything. The key never changes silently: a new key ships next to the old one for one release.

The engine kit ships burrowrelease and the public key burrow-release.pub: verify a manifest with burrowrelease verify (offline, no source code needed).
