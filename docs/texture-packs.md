# Texture packs

The engine embeds one block texture pack, imported once as plain PNGs (there is no resource-pack loader): the full 1.16 block set of Pixel Perfection CE
(`pixelperfection`, albedo only) in `assets/textures/pixelperfection`, accessed through `assets/blocktex`. `burrow assets textures` lists it with licence and coverage.

| id | licence | files | coverage |
|---|---|---|---|
| `pixelperfection` (default) | CC-BY-SA-4.0, attribution + ShareAlike; commercial use allowed | 922 PNG + 67 `.mcmeta`, 322 KiB | Minecraft Java 1.16.2 block set (454 block entries, 242 shapes reuse them) |
| `none` | - | - | flat colours |

`default` and new projects use `pixelperfection` (`burrow new` writes `"texture_pack": "pixelperfection"` and `"blocks": "shapes"`; `burrowedit` without `-project` does the same),
for its complete coverage of the extended block set ([blocks.md](blocks.md)) and one coherent style. Without the textures (`-tags nopp`) every block draws its flat fallback colour.
The extended blocks the pack lacks (1.17+: deepslate ores, copper, tuff, bamboo, cherry, mangrove, ...) are flat placeholders listed in [blocks.md](blocks.md#placeholders).
Released builds embed no other pack; asking for any other pack id fails with "not included in this build".

## Pixel Perfection CE

* Source `https://github.com/Athemis/PixelPerfectionCE`, commit `28e38cab7c1f03f86364ef704f705bebcc13cb3d`; imported by `scripts/import-pixelperfection.sh <checkout> <sha> <date>`
  (byte for byte; `manifest.json` has the SHA-256, size, dimensions and frame count of every file; the tests verify it).
* Licence CC-BY-SA-4.0, authors in `assets/textures/pixelperfection/NOTICE.md`. **ShareAlike**: the textures and any adaptation stay CC-BY-SA-4.0 whatever the licence of
  your game; `burrow build` prints the reminder when the pack is bundled and records `textures.licenses` in the build manifest. Compile out with `-tags nopp`
  (`burrow build --no-default-textures` builds burrowplay with `novnr,nopp`).
* Only `block/*.png` and the `*.png.mcmeta` animation descriptors. 856 files are 16x16; 66 are vertical strips of 16 px frames (fire, lava, portal, kelp, command blocks, lanterns...,
  `lava_flow`/`water_flow` are 32 px wide); the loader crops frame 0 in memory, animation is not implemented. One orphan `rail_golden_powered.png.mcmeta` ships upstream.
* Leaves, grass top/side overlay, grass, fern, vine, lily pad and water are gray/neutral tintable textures (grass top averages ~(141,130,113)): they need the biome tints
  listed in `mcnames.json` `tint_kinds`. `TintGain = 1.65` was calibrated for a gray level of 0.57; this pack is normalised to it: at load time (`blocktex.Faces.Images`) every tintable Pixel Perfection image
  (leaves, grass top, grass side overlay, ...) is converted to its gray luma and rescaled to a mean of `TintReference = 0.58`, so the same `TintGain` yields the biome colour. Shaders and the soft renderer are unchanged. A test checks the mean.
* No 1.17+ blocks (deepslate, copper, amethyst, tuff, moss, mud, cherry, bamboo planks, ...): `mcnames.json` `missing` lists 146 of them with a suggested flat average colour; the 75 that are full cubes are registered as flagged placeholders.
* Animation is not implemented: only frame 0 of the vertical strips is used (command blocks, lanterns, magma, sea lantern, prismarine, ...).
* Style: consistent saturated hand-drawn pixel art; a pack-wide look (see `docs/img/texture-pack-pixelperfection.png`, one tile per block entry). Visible defects: about 220
  files are optifine random variants (`stone1`..`stone10`, `grass1`, ...), emissive overlays (`*_e`), legacy aliases (`fence_oak`, `brick5`) or non-block assets (`debug`,
  `destroy_stage_*`, `empty_armor_slot_*`) listed under `auxiliary`; cutout blocks (glass panes, iron bars, ladders) are mostly transparent; no texture is missing for a mapped block.

## `mcnames.json`

`assets/blocktex/mcnames.json` (generated by `scripts/gen-mcnames.py`, loaded by `blocktex.LoadMCNames`) maps canonical block names (`oak_planks`, `stone_bricks`, `white_wool`...)
to files and faces: `kind` (`cube_all`, `top_side_bottom`, `cube_column`, `orientable`, `slab`, `pane`, `cross`, `tall_cross`, `crop`, `door`, `fluid`, `custom`...), `tex` roles,
`tint` (grass, foliage, water, ...), `emissive`, `translucent`. `derived` shapes (slabs, stairs, walls, fences, buttons, carpets...) reuse a base block's texture; `auxiliary`
classifies every other file; `missing` lists newer vanilla blocks without texture. Names are facts taken from the pack's file names; no game data is copied. A test checks
that every imported PNG is covered exactly once.

## Replace or remove

* `runtime.blocks` in `vox.project`: `"shapes"` (default, the only supported value; `"classic"` and `"extended"` are deprecated and resolve to it, see [blocks.md](blocks.md)).
* `runtime.texture_pack` in `vox.project`: `"default"` (the embedded Pixel Perfection CE), `"pixelperfection"` or `"none"` (flat colours); `burrowplay -textures default|pixelperfection|none`, `burrowedit -textures` override it.
* Your own textures: put `assets/textures/block/<name>.png` in your project (project overrides win over the embedded pack).
* Compile the pack out: `go build -tags nopp ./...` (`PackEmbedded` is false, layers are flat colours).

## Channel layout

Albedo sRGB RGB(A); normal R,G = xy, B = AO, A = height; specular R = smoothness, G = F0/metal index (230..255 metals),
B = porosity/SSS, A = emission (255 = none). `blocktex.BuildLayers` mips albedo in linear light, renormalises normals and keeps the
metal index (max) in specular.

## Rendering

See [rendering.md](rendering.md#block-textures-terrain). Registry block names map to textures through `engine.BlockTextureName` (aliases:
grass -> grass_block, wood/log -> oak_log, leaves -> oak_leaves, planks -> oak_planks); registered blocks without a texture stay flat. Tinted albedo
(leaves) is multiplied by the plains tint; the grass side overlay is composited with the tint baked in at upload.

## Tint formula (T3)

Vanilla-style tintable textures (grass top, leaves) are gray, about 0.57 on average once normalised (147/255 grass, 144/255 oak leaves).
No colormap ships, so plains colours are used (grass #91BD59, foliage #77AB2F, water #3F76E4). Final colour, per channel in
sRGB space (the same space as the sampled albedo): `texel * tint * TintGain` (scaled by `1/max` instead of clipped per channel when a channel exceeds 1, so bright texels keep their hue) with `TintGain = 1.65 ~ 1/gray`, so the
average on-screen albedo is about the tint colour (grass ~ (140,180,86)). Biome-varying colormaps are not implemented (fixed plains).
AO on tinted faces is softened. Debug: `BURROW_TEXDEBUG=albedo|tint|ao|normal|spec|light`.

## Render options

Strength of the maps is a render option, not part of the pack: normal relief x2.2 and specular x2.0 by default
(`-normal-strength`, `-spec-boost`; they only act on packs that carry normal/specular maps); grass/foliage tint varies per world column (`-biome-tint`), see docs/rendering.md.
