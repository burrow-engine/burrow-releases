The Go SDK in depth#

Everything a Go script can call lives in one package, burrow-engine/sdk/burrowsdk: one source file per domain, pure helpers mixed with host calls, and a generated file of typed component accessors. This page is the map of that package; the generated script API reference lists every function, type, constant and struct field with its doc comment, and script/ABI.md is the raw ABI underneath.

Core types#

Everything is keyed by Entity, a uint64 handle to a scene node (0 = none). The full field-by-field reference is the Types section of the script API:

typerole
Entitya scene node handle; Exists checks it
Scriptthe four hooks (OnStart, OnTick, OnEvent, OnDestroy), installed with Register or RegisterNamed from init()
Eventone delivered message: From, Kind, Payload
Errora failed host call: Op (the host function) and Code (an abi.Err* code); IsNotFound(err) matches ErrNotFound
TransformPos, Rot (Euler degrees), Scale; read/write with GetTransform/SetTransform
Writer/Readerbinary codec for State (see below)

Calling conventions#

  • Errors. Every host call returns an error that is an *Error (Op + Code), or nil. Check specific failures with IsNotFound. The error codes and their meanings are listed in errors and limits; the raw codes are the Err* constants of sdk/burrowsdk/abi.
  • Budgets. Every call is charged gas (50,000,000 per hook) and most calls have their own limits (payload 1 KiB, state 64 KiB, 4,096 block edits per call, ...). A call that exceeds a budget faults the whole transaction: its writes are discarded, see execution model.
  • Results. Reads that return bytes or lists (GetRaw, BlockDataIn, FindWith, ...) grow their buffer internally until the data fits; large answers report ErrTooSmall-style resizing transparently.

Simulation domain vs frame domain#

domainfileswhat it means for your script
Simulation (journaled, hashed, replayed)voxsdk.go, fields.go, components_gen.go, scene.go, blocks.go, bus.go, level.go, nav.go, net.go, physics.go, fluid.go, model.goChanges commit with the call, are saved, hashed and replayed exactly. LightAt, Voxel and the scene queries read the committed state (plus this call's own writes where documented).
Frame (queued requests)audio.go, particles.go, fx.go, anim.go, camera.go, gameui.goRequests take effect after the tick, in call order. They are deterministic (a replay shows the same effects) but never part of the StateHash, and they are ignored when the matching runtime.plugins.* is off.
Pure Go (no host call)tween.go, codec.go, parts of items.go, bus.go's BusKind, voxsdk.go's Rand*/CanonF32Free, safe to call anywhere — including from init() for everything except Rand*, which need a tick.

Pure helpers worth knowing#

These need no host call and no component, so they are the building blocks of State logic:

  • Binary state. Writer appends U8/Bool/U32/I32/U64/F32/String little-endian; Reader (from NewReader) reads them back, setting Reader.Err when it runs past the end. Encode with w.Bytes(), store with SetStateRaw, read with StateRaw. Faster and smaller than SaveState JSON, at the price of writing the layout yourself. CanonF32 canonicalises NaN so its payload bits never reach hashed state.
  • Tweens and cooldowns in tick time. Tween is plain JSON-able data: NewTween(from, to, durTicks, ease) starts one now, t.At(tick)/t.Now() evaluate it, t.Done(tick) reports the end. EaseKind has 13 curves (Linear, InQuad, OutCubic, OutBounce, SmoothStep, ...) and EaseKind.Apply maps [0,1] through one; Lerp(a, b, t) is the linear case. Cooldown is a one-field deadline: Start(n), Ready().
  • Item stacks. ItemStack{Item, Count} with Empty, Encode (the 6-byte wire form, ItemStackSize), DecodeItemStack, Split(n) and Merge(src, maxStack). Ids and limits come from the project: ItemIDByName, ItemInfo (ItemProps.MaxStack).
  • Block names with states. BlockBase("mymod:belt[facing=east]") gives "mymod:belt", BlockProp(name, "facing") gives "east".
  • Deterministic randomness. Rand(), RandFloat() in [0,1), RandN(n) in [0,n): a private stream per script entity, derived from the seed, entity, tick and draw index; it never touches the shared simulation RNG.
  • Event kinds. BusKind(topic) computes the kind a bus message arrives with; KindTimer, KindBlockBatch and KindBlockTick are reserved kinds handled by OnTimer/OnMessage and the block handlers.

Generated component accessors#

components_gen.go holds one Comp<Name> constant per built-in component (CompTransform = "transform", CompRenderCamera = "render.camera", ...) and, for every scalar field, a typed getter and setter (TransformPos(e), SetTransformPos(e, v), built on GetFloats/SetFieldRaw). It is generated from the same component schema as the inspector and the components reference: regenerate it with make sdk-gen after changing the schema (make sdk-check fails when it is stale). For object fields and custom components use the generic Get/Set/Patch or the fields.go accessors.

A complete example#

One module using registration, props, state, the codec, a tween, the bus and the transform — the same shapes the cookbook recipes use:

package main

import "burrow-engine/sdk/burrowsdk"

type props struct {
	Speed float32 `json:"speed"` // degrees per second
}

type state struct {
	Turns int `json:"turns"` // ticks since start, kept as binary state
}

const kindDone int32 = 1 // below 0x40000000: our own event kind

func init() {
	burrowsdk.OnMessage("game.reset", func(self, from burrowsdk.Entity, payload []byte) {
		_ = burrowsdk.SetStateRaw(new(burrowsdk.Writer).Bytes()) // clear the state
	})
	burrowsdk.Register(burrowsdk.Script{
		OnStart: func(self burrowsdk.Entity) {
			burrowsdk.Log(burrowsdk.LevelInfo, "spinner ready")
		},
		OnTick: func(self burrowsdk.Entity, dt float64) {
			p, err := burrowsdk.Props[props]()
			if err != nil {
				return
			}
			var st state
			r := burrowsdk.NewReader(burrowsdk.StateRaw())
			st.Turns = int(r.I32())
			if r.Err {
				st.Turns = 0 // first tick: empty state decodes as zeros anyway
			}
			tw := burrowsdk.NewTween(0, 1, 20, burrowsdk.OutQuad) // ease in over one second
			t, err := burrowsdk.GetTransform(self)
			if err != nil {
				return
			}
			t.Rot[1] += p.Speed * float32(dt) * float32(tw.Now())
			if err := burrowsdk.SetTransform(self, t); err != nil {
				return
			}
			st.Turns++
			w := new(burrowsdk.Writer).I32(int32(st.Turns))
			_ = burrowsdk.SetStateRaw(w.Bytes())
			if st.Turns == 20 {
				_ = burrowsdk.Emit(0, kindDone, []byte("one second"))
			}
		},
		OnEvent: func(self burrowsdk.Entity, ev burrowsdk.Event) {
			if ev.Kind == kindDone {
				burrowsdk.Logf("done, from=%d payload=%s", uint64(ev.From), ev.Payload)
			}
		},
	})
}

func main() {}

Where the full reference lives#

  • Script API reference (generated by make docs-gen): the host functions (the vox imports, from script/ABI.md), then the Go SDK functions grouped by source file, then every type with its struct fields, then every constant and variable — all with their doc comments.
  • From the command line or your IDE: go doc burrow-engine/sdk/burrowsdk and go doc burrow-engine/sdk/burrowsdk.<Name> show the same comments.
  • sdk/burrowsdk/abi declares the raw imports one-to-one (one function per ABI row, same signatures as the host-function table); use it only for custom wrappers, and note that outside wasip1 every call returns ErrUnavailable so tests can run on the host.
