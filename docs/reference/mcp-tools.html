MCP tools of the editor#

Generated by make docs-gen from the source code. Do not edit this page by hand: change the code or its doc comments and regenerate.

burrowedit -agent unix:<socket> (and burrow agent) serve 57 editor_* tools over MCP. Every mutation is journaled and undoable. Mode tags in the descriptions say where a tool may run (edit, play, pause). See agents.md for the workflow.

toolsummary

editor_anim_editEdit animation clips like the Animation panel: open or save a .anim file, create clips, add/move/delete keys and events, preview the pose at a time and record property edits as keys.
editor_audioAudio mixer (frame domain: never part of the document hash, not undoable).

editor_biomesWorld generator (kind: heightmap = v1, flat, biomes = v2), seed, sea level and, for the biomes generator, the biome list (id, name, minimap colour, grass/foliage/water tint).
editor_block_atRead one voxel of the effective world (overlay over base terrain).
editor_blocksThe block registry (name, color, solid, plus category, display name, search aliases, hardness and material for the known blocks, and for shaped blocks family, item, state and collision_boxes) usable as 'block'.
editor_cameraMove the editor camera: position/yaw/pitch, or focus a node (frames it), or aim at a point.
editor_create_nodeCreate a node (undoable).
editor_docs_readRead a documentation page (Markdown) by its path as returned by editor_docs_search or listed by editor_docs_read without arguments, optionally only the section under one heading anchor.
editor_docs_searchFull-text search of the Burrow documentation embedded in the editor (guides, tutorials and the generated reference of components, script API, MCP tools, CLI flags, project keys, input actions, blocks and render options).
editor_find_viewFind a clear, high viewpoint over a spot: samples the ground around near [x,z] within radius (default 24, max 128), lifts the eye height blocks above the ground there (default 10) and scores each by height, openness (free horizontal rays) and sky visibility, requires a clear line of sight to the target, then refines around the best coarse candidates.
editor_gameuiGame UI (HUD, menus, inventories; frame domain, never part of the document hash; docs/game-ui.md).
editor_graphicsGraphics of the viewport, switched at run time without a restart (a viewport setting, not part of the document; needs the windowed editor; docs/rendering.md).

editor_hierarchyThe scene tree as JSON: name, path, components, optional local transforms.
editor_interactOpen or close the door, trapdoor or fence gate at 'pos' (both halves of a door) as ONE undoable step; shaped blocks need runtime.blocks "shapes" (docs/block-shapes.md).
editor_journal_exportBounded export of the sim journal: the checkpoint snapshot (base64, present once the journal was compacted; refused above 4 MiB) plus the command tail (max_entries, default 1000, max 20000; truncated:true when cut).
editor_layersLayers: a node joins one through the layer component (saved in the scene); a child without one inherits its parent's.
editor_levelFixed levels: a hand-built voxel region plus spawn points, trigger zones, nodes and per-level settings, stored as levels/<id>.level in the project.
editor_lightLight of the world (docs/lighting.md; derived data, never part of the document hash).
editor_logTail of the editor console (engine messages, errors).
editor_microMicro-voxel editing: a cell of the world can be subdivided into a brick of n^3 micro voxels (n 2, 4, 8 or 16) of any blocks, a brick that becomes one block collapses back.
editor_modelVoxel model editor (.bmodel, package model).
editor_navNavigation and AI (docs/navigation-ai.md; needs runtime.plugins.nav or burrowedit -nav; without it state reports installed false and the other actions fail).
editor_newClear the scene (voxel edits are kept).
editor_node_opDelete, duplicate, rename or reparent a node (undoable).
editor_openOpen a .voxscn scene file inside the project directory or an allowed directory (replaces the scene, clears undo history).
editor_particlesParticle effects (frame domain: never part of the document hash).
editor_pauseToggle pause in play mode.
editor_place_on_groundSnap a scene node onto the terrain: its world y becomes the top of the ground under its world x,z plus offset (default 0, so a node whose origin is at its feet stands on the ground; use offset half the height for a centred cube).
editor_playSnapshot the world and start Play mode (fixed ticks run when editor_step is called or, in the windowed editor, every frame).
editor_redoRedo undone steps of one document's history (scene by default, see editor_undo).
editor_remove_componentRemove a component from a node (undoable).
editor_saveSave the scene to a path inside the project directory or an allowed directory (default: the open file).
editor_schemaList the scene components (name, fields with kind/range/tooltip) usable with editor_set_component / editor_create_node.
editor_script_cmdsAuthoring commands scripts queued with editor_cmd (zone_add, zone_remove, spawn_add, spawn_remove on the level draft, world blocks).
editor_script_debugScript debugger.

editor_selectSelect nodes by path (replaces the selection); an empty list clears it.
editor_selection_opOperate on the voxel region set with editor_tool_apply tool=selectbox: copy, cut, paste (at 'at'), fill (current block), replace (block 'from' by the current block), delete, rotate (90 degrees about Y, in place), mirror (axes), move (by 'delta'), clear.
editor_set_componentSet (add or replace) a component on a node from JSON data validated against the scene schema (undoable).
editor_set_transformSet a node's local transform; omitted fields keep their value (undoable).
editor_stateEditor state: mode (edit/play/pause), tick, hashes (engine_hash = raw sim hash, doc_hash = canonical document hash, world_hash = voxels), dirty flag, open scene path, selection, active voxel tool and settings, camera, undo/redo depth.
editor_stepAdvance the simulation by N fixed ticks (20 Hz), at most 2000 per call, in slices of 50 ticks that release the editor lock in between, within a 3 s time budget.
editor_stopStop play mode and atomically restore the world to the state at editor_play.
editor_texturePixel-art texture editor (package texedit): block textures 16x16..128x128 (top/side/bottom per block), item icons, layers.
editor_tool_applyApply a voxel tool as ONE undoable step.
editor_undoUndo steps (a drag, a stroke or a tool use is one step) of one document's history: the scene by default, or doc <name> for an asset editor (animation, model, texture, ...).
editor_verify_replayReplay checkpoint + journal in a fresh engine (the editor is not touched) and compare raw engine hashes.
editor_viewport_screenshotRender the editor viewport (terrain + scene meshes/sprites/lights) from the editor camera.
editor_voxel_groupVoxel groups: scene nodes (component voxel.group) that own a set of world voxels, so a structure moves, deletes, duplicates and undoes like an object.
editor_waterRead the water at a voxel: block, level (0 none, 1..7 flowing, 8 source), surface height 0..1 inside the cell, falling, flow direction (unit vector, x/y/z) and the state of the flow automaton (idle, active_cells, pending_wakeups, dropped).
editor_water_pourPour a volume of fine water into one block cell (the bucket): units 1..FineCapN^3 (a full block is 32N^3 units; N is fine_n of editor_water, 4 by default so a full block is 2048 and one eighth of a block is 256), spread from the floor of the cell up.
editor_water_wakeWake the water of an inclusive box (fluid_wake: rescan it and re-evaluate its bricks, for example after loading a world saved mid-flow; journaled, not an undo step) or, with refine true, turn its coarse flowing water (water_1..7, water_full) into fine bricks instead (fluid_refine, at most 65536 cells and the free brick budget; one undo step that puts the coarse blocks back; the new bricks move at the next simulation step).
editor_weatherRead or set the world weather (one undoable step).
editor_worldSave the voxel overlay to a .voxworld file, load one (undoable), or clear all voxel edits (undoable).

editor_anim#

List animation clips, state machines and the nodes that carry an anim.player, and control players: play a clip (optionally crossfaded, queued, looped or ping-ponged), stop, set the speed, set a state machine parameter or raise a trigger. Players are simulation components stepped by the fixed tick (editor_step or Play), so what they drive is deterministic and journaled; each control action is ONE undo step in edit mode. A clip of the open animation document is visible here at once.

parametertyperequireddescription
actionstringWhat to do (default list) (one of: list, play, stop, speed, param, trigger)
clipstringClip name (play)
fadenumberCrossfade seconds (play)
machinestringState machine to attach (param)
modestringPlayback mode (play) (one of: once, loop, pingpong)
namestringParameter or trigger name (param, trigger)
pathstringNode path of the player (play, stop, speed, param, trigger)
queuebooleanPlay after the current clip ends (play)
speednumberSpeed multiplier 0..100, 0 = 1 (speed)
valuenumberParameter value; bool is 0/1 (param)

editor_anim_edit#

Edit animation clips like the Animation panel: open or save a .anim file, create clips, add/move/delete keys and events, preview the pose at a time and record property edits as keys. Every edit is ONE undo step (editor_undo). Times are seconds. A key value is a number (float, int), true/false (bool), [x,y,z] (vec3), [x,y,z,w] or Euler degrees [x,y,z] (quat), [r,g,b,a] (color). prop is component.field (transform.pos, transform.rot, transform.scale, or any float/int/bool/vec3 field of a component); target is a node path relative to the animated root node ('' = the root itself). Previewing writes the pose on the scene until editor_anim_edit preview off, a save or any other edit. Allowed modes: edit.

parametertyperequireddescription
actionstringWhat to do (default info) (one of: info, new_file, open, save, clip_new, clip_delete, clip_select, clip_props, root, key_set, key_move, key_delete, track_delete, event_add, event_delete, scrub, preview, record)
argstringEvent argument (event_add)
clipstringClip name
easearray of numberBezier handles x1,y1,x2,y2 (key_set with interp bezier)
eventstringEvent name (event_add, event_delete)
interpstringInterpolation of the segment after the key (key_set) (one of: linear, step, smooth, cubic, bezier)
kindstringTrack kind (key_set; inferred from the property when omitted) (one of: float, vec3, quat, color, bool, int)
lengthnumberClip length in seconds (clip_props)
loopbooleanClip loops by default (clip_props)
onbooleanTurn preview or record on or off (preview, record)
pathstringProject-relative .anim path (open, save) or node path (root)
propstringProperty, component.field (key and track actions)
renamestringNew clip name (clip_props)
targetstringNode path relative to the root (key and track actions)
timenumberSeconds (key actions, events, scrub)
tonumberNew time in seconds (key_move)
valueanyKey value, see the tool description

editor_audio#

Audio mixer (frame domain: never part of the document hash, not undoable). action state (default) returns the mixer: buses (volume, mute, duck, peak), voices (id, name, bus, spatial, distance, gain), counters and the listener. list returns the .wav/.ogg project assets. play {sound, bus?, volume?, pitch?, loop?, pos?} starts a sound (pos makes it 3D) and returns the voice id; stop {voice? | bus?} stops one voice, a bus or everything; bus {bus, volume?, mute?} sets a bus volume; music {sound, fade?} crossfades the music (no sound fades it out); render {ms} renders the next ms of audio offline (null backend only) and returns peak and rms so a sound can be verified without hearing it.

fadenumberFade seconds (range 0..60)
loopbooleanRepeat until stopped
msintegerMilliseconds to render offline (range 1..30000)
mutebooleanMute or unmute the bus
pitchnumberPlayback speed 0.1..4 (range 0.1..4)
posarray of numberWorld position: the sound becomes 3D
soundstringSound: a project asset path (.wav, .ogg)
voiceintegerVoice id from play/state (range 1..2147483647)
volumenumberLinear gain 0..4 (range 0..4)

editor_blocks#

The block registry (name, color, solid, plus category, display name, search aliases, hardness and material for the known blocks, and for shaped blocks family, item, state and collision_boxes) usable as 'block'. Shaped blocks are named item[props] (the default state is the bare item name). The full list is about 1500 entries: filter it. query matches names, display names and aliases (English and French); category is one of Naturel, Pierre, Bois, Laine/Couleurs, Verre, Minerais, Nether/End, Décoration, Lumière, Liquide, Technique, Dalles, Escaliers, Clôtures, Portes, Plantes (case-insensitive); material and family are exact; limit caps the count; names_only returns just the names. Shaped states: pass family=stairs (or slab, door, trapdoor, fence, wall, pane, ...) and names_only for the items, then name a state as item[facing=east,half=top].

Hints: read-only.

parametertyperequireddescription
categorystringPalette category (see the description)
familystringShaped family: slab, stairs, wall, fence, fence_gate, door, trapdoor, pane, torch, carpet, ladder, cross, ...
limitintegerReturn at most this many blocks (default all) (range 1..5000)
materialstringMaterial family: stone, dirt, grass, sand, gravel, wood, glass, wool, metal, snow, ice, leaves, nether, bone, coral, organic, liquid
names_onlybooleanReturn only the names (cheap)
querystringSubstring of a name, display name or alias
statesbooleanInclude the non-default states of shaped items (default true; false lists each item once under its bare name)

editor_find_view#

Find a clear, high viewpoint over a spot: samples the ground around near [x,z] within radius (default 24, max 128), lifts the eye height blocks above the ground there (default 10) and scores each by height, openness (free horizontal rays) and sky visibility, requires a clear line of sight to the target, then refines around the best coarse candidates. The target is look_at [x,y,z] or, by default, the ground at near. Returns position, yaw, pitch (the editor_camera convention), look_at and distance; with apply true the editor camera is moved there. found false means no candidate saw the target (raise height or radius). Read only unless apply.

parametertyperequireddescription
applybooleanalso move the editor camera there
heightintegerEye height above the ground (default 10) (range 1..200)
look_atarray of numberTarget point (default: the ground at near)
neararray of numberyesCentre [x,z] of the search
radiusintegerSearch radius in blocks (default 24) (range 1..128)

Widgets: label, image, button, bar, panel, list, grid, input, dialog, stack, spacer. On by default (runtime.plugins.gameui:false disables it).

editor_layers#

Layers: a node joins one through the layer component (saved in the scene); a child without one inherits its parent's. Visibility and lock are editor-only (scene sidecar, never in the game): a hidden layer is not drawn in the editor viewport (its voxel groups neither) and not pickable; a locked one is not pickable and the voxel tools cannot change its voxel groups. action list (default) returns {name, hidden, locked, nodes}. create {name}. rename {name, to}. delete {name} (its nodes stay, they leave the layer). hide|show|lock|unlock {name}. assign {paths, name} moves nodes to a layer (name "" removes them from their layer; one undo step). select {name} selects its nodes.

parametertyperequireddescription
actionstringWhat to do (default list) (one of: list, create, rename, delete, hide, show, lock, unlock, assign, select)
namestringLayer name
pathsarray of stringNode paths (assign)
tostringNew name (rename)

editor_level#

Fixed levels: a hand-built voxel region plus spawn points, trigger zones, nodes and per-level settings, stored as levels/<id>.level in the project. action state (default) returns the draft (spawns, zones, settings; world block coordinates). list returns the project's levels. info {id} describes one (hash, chunks, counts). save {id, min, max, nodes_root?} stores the world box [min,max] (grown to chunk boundaries, at most 4096 chunks) with the draft and the children of the scene node nodes_root as the level (atomic write; edit mode only). open {id, origin?} places the level into the document as a journaled edit (origin in chunk coordinates) and loads its markers into the draft (edit mode only). spawn_add {name, pos, yaw?, tags?} marks a spawn point. zone_add {name, min, max (inclusive blocks), kind?: zone|trigger, target?, target_spawn?, props?} marks a zone; a trigger switches to level target when an actor stands in it. remove {kind: spawn|zone, name}. settings {sky?, weather?, weather_intensity?, fog?: {density, color}, gravity?, kill_y?, bounds?: {min, max}} replaces the draft settings (kill_y and bounds are world blocks, stored relative to the region origin). clear empties the draft. Projects enable the runtime with runtime.plugins.levels:true.

parametertyperequireddescription
actionstringWhat to do (default state) (one of: state, list, info, save, open, spawn_add, zone_add, remove, settings, clear)

Voxel groups: scene nodes (component voxel.group) that own a set of world voxels, so a structure moves, deletes, duplicates and undoes like an object. The blocks always stay in the world (.voxworld), so games and collisions are unchanged. action list (default) returns every group {path, origin, size, blocks, layer}. info {path} one group. create {min, max, name?} groups the non-air blocks of a box (inclusive corners) without moving them; deleting that group later leaves air. stamp {asset, origin, name?, parent?} places a project .vox model as a group (minimum corner at origin), covering what is there; deleting it puts that back. bake {path} drops the record and keeps the blocks as plain terrain. Move or turn a group with editor_set_transform (whole cells; rotation snaps to quarter turns about the node corner on any axis, scale is ignored). Hidden layers (editor_layers) hide its voxels in the editor viewport.

parametertyperequireddescription
actionstringWhat to do (default list) (one of: list, info, create, stamp, bake)
assetstringProject .vox path (stamp)
maxarray of integerOpposite box corner, inclusive (create)
minarray of integerBox corner (create)
namestringNode name (create, stamp; default Group / the asset name)
originarray of integerMinimum corner of the stamp (stamp)
parentstringParent node path (stamp; default root)
pathstringGroup node path (info, bake)

editor_water#

Read the water at a voxel: block, level (0 none, 1..7 flowing, 8 source), surface height 0..1 inside the cell, falling, flow direction (unit vector, x/y/z) and the state of the flow automaton (idle, active_cells, pending_wakeups, dropped). With the fine water (the editor default, docs/water-fine.md) it also reports fine, fine_n, brick (the cell is held by sub-cell bricks), units (water volume of the cell; full_units is a full block), surface (highest water surface in a brick cell), bricks and the volume ledger (held, created, drained, evaporated, displaced); detail true adds the per sub-column units and every sub-cell fill. Read only. Water moves only while the simulation ticks: place a source with editor_tool_apply (block water) or pour a volume with editor_water_pour, then editor_play and editor_step; in edit mode nothing flows. Placing or removing water and undoing it are ordinary voxel edits (undoable, journaled).

Hints: read-only.

parametertyperequireddescription
detailbooleanalso list the per sub-column units and the sub-cell fills of a fine brick (default false)
posarray of integeryesVoxel

editor_water_pour#

Pour a volume of fine water into one block cell (the bucket): units 1..FineCapN^3 (a full block is 32N^3 units; N is fine_n of editor_water, 4 by default so a full block is 2048 and one eighth of a block is 256), spread from the floor of the cell up. What does not fit is not added. The cell must be air, a fragile block (destroyed), flowing water or fine water. It is one undoable step (undo restores the exact previous content) and a journaled command; the water moves only while the simulation ticks. Fails when the editor runs the coarse water (burrowedit -no-fine-water). Returns editor_water of the cell.

parametertyperequireddescription
posarray of integeryesBlock cell
unitsintegeryesWater units to add (range 1..16384)

editor_water_wake#

Wake the water of an inclusive box (fluid_wake: rescan it and re-evaluate its bricks, for example after loading a world saved mid-flow; journaled, not an undo step) or, with refine true, turn its coarse flowing water (water_1..7, water_full) into fine bricks instead (fluid_refine, at most 65536 cells and the free brick budget; one undo step that puts the coarse blocks back; the new bricks move at the next simulation step). Refine fails on the coarse automaton.

parametertyperequireddescription
maxarray of integeryesBox maximum
minarray of integeryesBox minimum
refinebooleanconvert coarse flowing water to fine bricks (default false)

editor_weather#

Read or set the world weather (one undoable step). With no arguments it returns the state; 'at' also samples the local weather at a position (rain falls as snow only where the temperature is at or below 0 C). The simulation is off until you send enabled:true; it is deterministic and journaled (same seed + commands => same weather). Changes ease in unless instant:true. intensity 0..1 drives precipitation (rain/storm/snow), fog density (fog) or cloud cover (clear/cloudy).

parametertyperequireddescription
atarray of numberAlso sample the local weather at this world position
covernumberCloud cover target 0..1 (range 0..1)
enabledbooleanTurn the weather simulation on or off
freezebooleanFreeze the current front (no new front starts)
freeze_timebooleanStop the day clock
instantbooleanSkip the easing: values jump to the targets
intensitynumber0..1, see the tool description (range 0..1)
seasonsbooleanSeasonal temperature cycle
timenumberTime of day as a day fraction (0 midnight, 0.25 sunrise, 0.5 noon, 0.75 sunset) (range 0..1)
typestringStart this front now (one of: clear, cloudy, fog, light_rain, heavy_rain, storm, snow)
wind_autobooleanRelease a held wind back to the random walk
wind_dirnumberDegrees, the heading the wind blows toward (0 = +X, 90 = +Z); holds the wind
wind_speednumberm/s; holds the wind (range 0..30)

Save the voxel overlay to a .voxworld file, load one (undoable), or clear all voxel edits (undoable). Files must be inside the project directory or an allowed directory. Edit mode only. Allowed modes: edit.

Hints: destructive.
