# Project file

> Generated by `make docs-gen` from the source code. Do not edit this page by hand: change the code or its doc comments and regenerate.

A project is a folder with a `vox.project` manifest (JSON). The sections below list every key. Keys under `runtime` configure `burrowplay`, the exported game and the editor's Play mode. Everything is additive: a missing key keeps the default in the description, and unknown keys are rejected with a message naming the valid ones.

## runtime.script_limits

ScriptLimits is the "runtime.script_limits" section; every field is optional (0 = the default of script.Config).

| key | type | description |
|---|---|---|
| `runtime.script_limits.gas` | `int64` | Gas is the deterministic instruction budget of one guest call (default 50,000,000, at most 2,000,000,000). A mod whose manager script walks thousands of machines in one call needs more. Exhaustion is a fault, counted like any other. |
| `runtime.script_limits.memory_pages` | `uint32` | MemoryPages caps guest linear memory in 64 KiB pages (default 512 = 32 MiB, at most 4096; a Go guest needs about 180 pages to start). Raise it for scripts that hold large tables of machines. |
| `runtime.script_limits.max_faults` | `uint32` | MaxFaults is the number of faults before a script is disabled (default 3, at most 1000). |
| `runtime.script_limits.keep_memory` | `bool` | KeepMemory gives every script node its own guest instance whose memory is not reset between calls, so ordinary Go globals and heap persist across ticks. Single player only (rejected with runtime.plugins.net, a replicated net_model or a dedicated server); a fault, a hot reload or a save load restarts the memory from the module image. See docs/scripting/02-execution-model.md. |
| `runtime.script_limits.per_script` | `*ScriptBudget` | PerScript is the host call budget of one script transaction, every script separately (default 1,000 calls, 1 MiB, 32 spawns, 4,096 voxel edits, 64 events). |
| `runtime.script_limits.per_tick` | `*ScriptBudget` | PerTick is the host call budget of all scripts together in one tick (default 200,000 calls, 64 MiB, 1,024 spawns, 262,144 voxel edits, 4,096 events). |
