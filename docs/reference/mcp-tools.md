## editor_anim

List animation clips, state machines and the nodes that carry an anim.player, and control players: play a clip (optionally crossfaded, queued, looped or ping-ponged), stop, set the speed, set a state machine parameter or raise a trigger. Players are simulation components stepped by the fixed tick (editor_step or Play), so what they drive is deterministic and journaled; each control action is ONE undo step in edit mode. A clip of the open animation document is visible here at once.

| `machine` | string |  | State machine to attach (param) |

## editor_anim_edit

Every edit is ONE undo step (editor_undo). Times are seconds. A key value is a number (float, int), true/false (bool), [x,y,z] (vec3), [x,y,z,w] or Euler degrees [x,y,z] (quat), [r,g,b,a] (color). prop is component.field (transform.pos, transform.rot, transform.scale, or any float/int/bool/vec3 field of a component); target is a node path relative to the animated root node ('' = the root itself). Previewing writes the pose on the scene until editor_anim_edit preview off, a save or any other edit. Allowed modes: edit.

## editor_audio

Audio mixer (frame domain: never part of the document hash, not undoable). action state (default) returns the mixer: buses (volume, mute, duck, peak), voices (id, name, bus, spatial, distance, gain), counters and the listener. list returns the .wav/.ogg project assets. play {sound, bus?, volume?, pitch?, loop?, pos?} starts a sound (pos makes it 3D) and returns the voice id; stop {voice? | bus?} stops one voice, a bus or everything; bus {bus, volume?, mute?} sets a bus volume; music {sound, fade?} crossfades the music (no sound fades it out); render {ms} renders the next ms of audio offline (null backend only) and returns peak and rms so a sound can be verified without hearing it.

| parameter | type | required | description |
|---|---|---|---|
| `action` | string |  | What to do (default state) (one of: state, list, play, stop, bus, music, render) |
| `bus` | string |  | Mixer bus (one of: sfx, music, ambient, ui, master) |
| `fade` | number |  | Fade seconds (range 0..60) |
| `loop` | boolean |  | Repeat until stopped |
| `ms` | integer |  | Milliseconds to render offline (range 1..30000) |
| `mute` | boolean |  | Mute or unmute the bus |
| `pitch` | number |  | Playback speed 0.1..4 (range 0.1..4) |
| `pos` | array of number |  | World position: the sound becomes 3D |
| `sound` | string |  | Sound: a project asset path (.wav, .ogg) |
| `voice` | integer |  | Voice id from play/state (range 1..2147483647) |
| `volume` | number |  | Linear gain 0..4 (range 0..4) |

## editor_blocks

The block registry (name, color, solid, plus category, display name, search aliases, hardness and material for the known blocks, and for shaped blocks family, item, state and collision_boxes) usable as 'block'. Shaped blocks are named item[props] (the default state is the bare item name). The full list is about 1500 entries: filter it. query matches names, display names and aliases (English and French); category is one of Naturel, Pierre, Bois, Laine/Couleurs, Verre, Minerais, Nether/End, Décoration, Lumière, Liquide, Technique, Dalles, Escaliers, Clôtures, Portes, Plantes (case-insensitive); material and family are exact; limit caps the count; names_only returns just the names. Shaped states: pass family=stairs (or slab, door, trapdoor, fence, wall, pane, ...) and names_only for the items, then name a state as item[facing=east,half=top].

Hints: read-only.

| parameter | type | required | description |
|---|---|---|---|
| `category` | string |  | Palette category (see the description) |
| `family` | string |  | Shaped family: slab, stairs, wall, fence, fence_gate, door, trapdoor, pane, torch, carpet, ladder, cross, ... |
| `limit` | integer |  | Return at most this many blocks (default all) (range 1..5000) |
| `material` | string |  | Material family: stone, dirt, grass, sand, gravel, wood, glass, wool, metal, snow, ice, leaves, nether, bone, coral, organic, liquid |
| `names_only` | boolean |  | Return only the names (cheap) |
| `query` | string |  | Substring of a name, display name or alias |
| `states` | boolean |  | Include the non-default states of shaped items (default true; false lists each item once under its bare name) |

## editor_find_view

Find a clear, high viewpoint over a spot: samples the ground around near [x,z] within radius (default 24, max 128), lifts the eye height blocks above the ground there (default 10) and scores each by height, openness (free horizontal rays) and sky visibility, requires a clear line of sight to the target, then refines around the best coarse candidates. The target is look_at [x,y,z] or, by default, the ground at near. Returns position, yaw, pitch (the editor_camera convention), look_at and distance; with apply true the editor camera is moved there. found false means no candidate saw the target (raise height or radius). Read only unless apply.

| parameter | type | required | description |
|---|---|---|---|
| `apply` | boolean |  | also move the editor camera there |
| `height` | integer |  | Eye height above the ground (default 10) (range 1..200) |
| `look_at` | array of number |  | Target point (default: the ground at near) |
| `near` | array of number | yes | Centre [x,z] of the search |
| `radius` | integer |  | Search radius in blocks (default 24) (range 1..128) |

## editor_model

Voxel model editor (.bmodel, package model). Declarative and deterministic: send ops (JSON list in ops, or the text DSL in dsl, one op per line `box min=[0,0,0] max=[7,7,7] mat=wood`) and the same ops always give a byte-identical model; the op list is stored with the asset. Coordinates: x right, y up, z toward the viewer; a cell fills [x,x+1); centres and pivots are corner coordinates. Ops: size, material{name,color,emissive,gloss,alpha}, use, part{name,parent,pivot}, attach, primitives box|sphere|ellipsoid|cylinder|cone|torus|capsule|voxel|line with mode add|sub|and|paint (CSG union/subtract/intersect), fill, clear, mirror, array, repeat{count,offset,ops}, translate, rotate, flip, scale, hollow, erode, dilate, smooth, displace (noise), paint (rules all|gradient|speckle|replace), stamp{pos,size,mats,data} (paste a copied box of voxels; build it with model.StampOp). ## editor_step

| parameter | type | required | description |
|---|---|---|---|
| `ticks` | integer | yes | Ticks (range 1..2000) |

## editor_stop

Stop play mode and atomically restore the world to the state at editor_play.

Hints: destructive.

No parameters.

## editor_texture

Pixel-art texture editor (package texedit): block textures 16x16..128x128 (top/side/bottom per block), item icons, layers. Declarative and deterministic: ops (JSON list) give byte-identical PNGs; the recipe is stored next to the PNG. Ops: size{count|w,h}, palette{name,color}, lock{colors} (palette lock), fill, gradient{from,to,dir v|h|d|r,count}, noise{kind value|perlin,seed,scale,colors|from,to,octaves,strength}, dither{from,to,kind bayer4|bayer2|checker,dir|strength}, speckle{colors,density,seed}, pattern{kind bricks|planks|cobble|ore|grass_edge|checker|stripes,colors,mortar,seed,bw,bh,gap,cell,depth,count}, ascii{grid,legend,pos}, pixel, line, rect, ellipse{hollow}, erase, clear, flood, replace, outline{kind outer|inner|both|border}, shade{kind edges|bevel|relief}, hue{deg,sat,light}, seamless, quantize{colors}, offset, flip, rotate, layer{action new|select|delete|duplicate|merge_down|opacity|visible|lock|blend,name,opacity,visible,locked,kind normal|multiply|screen|overlay (blend)} (a locked layer refuses drawing ops). One-click material styles: texedit.StyleOps(style, base, accent, seed, w, h) returns the whole op stack (Stone, Planks, Bricks, Cobble, Metal, Grass, Sand, Ore, Fabric; the pattern steps divide the size, so tiled styles tile). Colours are #rrggbb, #rrggbbaa, transparent or a palette name. All noise is periodic so noise textures tile. Limits: 128x128, 2048 ops, 8 layers, 1 MiB PNG. action state (default) | new {kind block|item,name,w,h} | ops {ops} one undo step (editor_undo with doc=texture), returns the texture tiled 3x3, a block-in-world render, mips and stats | get (recipe) | ascii (pixels as a character grid + legend) | stats | preview {mode tile|block|mips|all, top, side, bottom} (face values: 'current' or a saved texture name; the block render shows 3x3 blocks) | save {kind,name | block,face top|side|bottom} writes textures/<kind>/<name>.png in the PROJECT (override layer over the bundled packs, which are never modified) and hot reloads block textures in the running game | open {kind,name} | list {kind}. Block faces: save {block:"grass_block", face:"side"} resolves the pack texture name that face samples (a texture shared by several blocks overrides all of them).

| parameter | type | required | description |
|---|---|---|---|
| `action` | string |  | What to do (default state) (one of: state, new, ops, get, ascii, stats, preview, save, open, list) |
| `block` | string |  | save: block name whose face texture to write |
| `bottom` | string |  | preview: bottom face texture |
| `face` | string |  | save: top, side or bottom (one of: top, side, bottom) |
| `h` | integer |  | new: height (range 4..128) |
| `kind` | string |  | block (textures/block/) or item (textures/item/) (one of: block, item) |
| `mode` | string |  | preview mode (one of: tile, block, mips, all) |
| `name` | string |  | Texture name: lowercase letters, digits, _ |
| `no_preview` | boolean |  | ops: skip the images |
| `ops` | array of object |  | Texture ops (JSON list) |
| `side` | string |  | preview: side face texture |
| `size` | integer |  | preview size in pixels (default 384) (range 64..768) |
| `top` | string |  | preview: top face texture ('current' or a saved block texture name) |
| `w` | integer |  | new: width (range 4..128) |

## editor_tool_apply

Apply a voxel tool as ONE undoable step. place/erase/paint/flood/eyedropper use 'pos' (the clicked voxel) and 'normal' (face normal; place puts the block on pos+normal); box/sphere/line/selectbox use 'start' and 'end' (sphere radius = distance start-end). Terrain tools: raise/lower (column sculpt at pos, size, strength = height per dab, hardness = falloff), flatten (to pos.y or 'level'), smooth, ramp (start to end), surface (recolour the top layers), replace (from -> block in the brush), extrude (face at pos+normal pushed by 'amount', negative pulls), scatter (kind, density percent, seed). invert swaps place/erase and raise/lower, empties with flood and flips the extrusion. dry_run returns the count and bounds without writing. Settings (block, size, shape, symmetry, hollow, strength, hardness, surface_only, radial, seed, density, from, kind, face_all) persist for later calls. Returns the number of voxels changed.

| parameter | type | required | description |
|---|---|---|---|
| `amount` | integer |  | Extrusion in voxels, negative pulls the face in (range -64..64) |
| `block` | string |  | Block name from editor_blocks |
| `density` | integer |  | Scatter density in percent (range 0..100) |
| `dry_run` | boolean |  | Compute and report the changes without writing |
| `end` | array of integer |  | Drag end voxel |
| `face_all` | boolean |  | Extrude the whole connected face, not only the brush footprint |
| `from` | string |  | Replace: block to replace (default: the block under pos) |
| `hardness` | integer |  | Falloff: percent of the radius applied fully, 0..100 (100 = hard edge) (range 0..100) |
| `hollow` | boolean |  | Hollow box/sphere |
| `invert` | boolean |  | Shift behaviour: place<->erase, raise<->lower, flood empties, extrusion flips |
| `kind` | string |  | Scatter kind (one of: tree, bush, rock, plant) |
| `level` | integer |  | Flatten height (default pos.y) (range -1048576..1048576) |
| `normal` | array of integer |  | Face normal, e.g. [0,1,0] for the top face |
| `origin` | array of integer |  | Symmetry origin voxel |
| `pos` | array of integer |  | Target voxel |
| `radial` | integer |  | Radial symmetry copies around the vertical axis through origin (0/1 = off) (range 0..16) |
| `seed` | integer |  | Seed of the dither and of scatter (range 0..2147483647) |
| `shape` | string |  | Brush shape (one of: cube, sphere, cylinder, cone, disc) |
| `size` | integer |  | Brush size 1..64 (range 1..64) |
| `start` | array of integer |  | Drag start voxel |
| `strength` | integer |  | Height per dab / smoothing passes / surface depth 1..16 (range 1..16) |
| `surface_only` | boolean |  | Only touch the surface voxels |
| `symmetry` | string |  | Mirror axes: any of x,y,z e.g. "xz" |
| `tool` | string | yes | Tool (one of: place, erase, paint, eyedropper, box, sphere, line, flood, selectbox, raise, lower, flatten, smooth, ramp, surface, replace, extrude, scatter) |

## editor_voxel_group

Voxel groups: scene nodes (component `voxel.group`) that own a set of world voxels, so a structure moves, deletes, duplicates and undoes like an object. The blocks always stay in the world (.voxworld), so games and collisions are unchanged. action list (default) returns every group {path, origin, size, blocks, layer}. info {path} one group. create {min, max, name?} groups the non-air blocks of a box (inclusive corners) without moving them; deleting that group later leaves air. stamp {asset, origin, name?, parent?} places a project .vox model as a group (minimum corner at origin), covering what is there; deleting it puts that back. bake {path} drops the record and keeps the blocks as plain terrain. Move or turn a group with editor_set_transform (whole cells; rotation snaps to quarter turns about the node corner on any axis, scale is ignored). Hidden layers (editor_layers) hide its voxels in the editor viewport.

| parameter | type | required | description |
|---|---|---|---|
| `action` | string |  | What to do (default list) (one of: list, info, create, stamp, bake) |
| `asset` | string |  | Project .vox path (stamp) |
| `max` | array of integer |  | Opposite box corner, inclusive (create) |
| `min` | array of integer |  | Box corner (create) |
| `name` | string |  | Node name (create, stamp; default Group / the asset name) |
| `origin` | array of integer |  | Minimum corner of the stamp (stamp) |
| `parent` | string |  | Parent node path (stamp; default root) |
| `path` | string |  | Group node path (info, bake) |

## editor_water

Read the water at a voxel: block, level (0 none, 1..7 flowing, 8 source), surface height 0..1 inside the cell, falling, flow direction (unit vector, x/y/z) and the state of the flow automaton (idle, active_cells, pending_wakeups, dropped). With the fine water (the editor default, docs/water-fine.md) it also reports fine, fine_n, brick (the cell is held by sub-cell bricks), units (water volume of the cell; full_units is a full block), surface (highest water surface in a brick cell), bricks and the volume ledger (held, created, drained, evaporated, displaced); detail true adds the per sub-column units and every sub-cell fill. Read only. Water moves only while the simulation ticks: place a source with editor_tool_apply (block water) or pour a volume with editor_water_pour, then editor_play and editor_step; in edit mode nothing flows. Placing or removing water and undoing it are ordinary voxel edits (undoable, journaled).

Hints: read-only.

| parameter | type | required | description |
|---|---|---|---|
| `detail` | boolean |  | also list the per sub-column units and the sub-cell fills of a fine brick (default false) |
| `pos` | array of integer | yes | Voxel |

## editor_water_pour

Pour a volume of fine water into one block cell (the bucket): units 1..FineCap*N^3 (a full block is 32*N^3 units; N is fine_n of editor_water, 4 by default so a full block is 2048 and one eighth of a block is 256), spread from the floor of the cell up. What does not fit is not added. The cell must be air, a fragile block (destroyed), flowing water or fine water. It is one undoable step (undo restores the exact previous content) and a journaled command; the water moves only while the simulation ticks. Fails when the editor runs the coarse water (burrowedit -no-fine-water). Returns editor_water of the cell.

| parameter | type | required | description |
|---|---|---|---|
| `pos` | array of integer | yes | Block cell |
| `units` | integer | yes | Water units to add (range 1..16384) |

## editor_water_wake

Wake the water of an inclusive box (fluid_wake: rescan it and re-evaluate its bricks, for example after loading a world saved mid-flow; journaled, not an undo step) or, with refine true, turn its coarse flowing water (water_1..7, water_full) into fine bricks instead (fluid_refine, at most 65536 cells and the free brick budget; one undo step that puts the coarse blocks back; the new bricks move at the next simulation step). Refine fails on the coarse automaton.

| parameter | type | required | description |
|---|---|---|---|
| `max` | array of integer | yes | Box maximum |
| `min` | array of integer | yes | Box minimum |
| `refine` | boolean |  | convert coarse flowing water to fine bricks (default false) |

## editor_weather

Read or set the world weather (one undoable step). With no arguments it returns the state; 'at' also samples the local weather at a position (rain falls as snow only where the temperature is at or below 0 C). The simulation is off until you send enabled:true; it is deterministic and journaled (same seed + commands => same weather). Changes ease in unless instant:true. intensity 0..1 drives precipitation (rain/storm/snow), fog density (fog) or cloud cover (clear/cloudy).

| parameter | type | required | description |
|---|---|---|---|
| `at` | array of number |  | Also sample the local weather at this world position |
| `cover` | number |  | Cloud cover target 0..1 (range 0..1) |
| `enabled` | boolean |  | Turn the weather simulation on or off |
| `freeze` | boolean |  | Freeze the current front (no new front starts) |
| `freeze_time` | boolean |  | Stop the day clock |
| `instant` | boolean |  | Skip the easing: values jump to the targets |
| `intensity` | number |  | 0..1, see the tool description (range 0..1) |
| `seasons` | boolean |  | Seasonal temperature cycle |
| `time` | number |  | Time of day as a day fraction (0 midnight, 0.25 sunrise, 0.5 noon, 0.75 sunset) (range 0..1) |
| `type` | string |  | Start this front now (one of: clear, cloudy, fog, light_rain, heavy_rain, storm, snow) |
| `wind_auto` | boolean |  | Release a held wind back to the random walk |
| `wind_dir` | number |  | Degrees, the heading the wind blows toward (0 = +X, 90 = +Z); holds the wind |
| `wind_speed` | number |  | m/s; holds the wind (range 0..30) |
