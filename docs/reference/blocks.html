Block list#

Generated by make docs-gen from the source code. Do not edit this page by hand: change the code or its doc comments and regenerate.

The block list holds 65 blocks in 10 categories: the 47 core blocks every project has plus the 18 full cubes of the extended set (runtime.blocks: shapes). Scripts and tools use the name (voxel_set, block_id_by_name, editor_tool_apply); the palette also searches the display name and the aliases. Hardness is the mining-time factor (-1 cannot be broken); light is the block light level 0..15 the block emits.
