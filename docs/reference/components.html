Scene components#

Generated by make docs-gen from the source code. Do not edit this page by hand: change the code or its doc comments and regenerate.

The scene schema registers 59 component types. A scene file stores each node's components by these names; the inspector, the editor_set_component tool and the script host functions entity_get_component / entity_set_component all use the same names and JSON fields. The default column is the zero value of the field's Go type, which is what a field takes when it is left out; where a component fills in a different value when it loads (the transform scale, for example) its description says so.

Ranges are checked when a scene loads and by the inspector. Field types: bool, int, float, string, vec3 (three numbers), entity (a reference to another node) and object (a nested structure, edited as JSON).

transform#

Transform is a node's local placement relative to its parent. Rot holds Euler angles in degrees: X = pitch (about X), Y = yaw (about Y), Z = roll (about Z). The rotation matrix is R = Ry(yaw) * Rx(pitch) * Rz(roll). The local matrix is T(Pos) * R * S(Scale). JSON form: {"pos":[x,y,z],"rot":[pitch,yaw,roll],"scale":[x,y,z]}; omitted fields default to pos 0, rot 0, scale 1.

fieldtyperangedefaultdescription
posvec3[0,0,0]Position relative to the parent, in voxels
rotvec3[0,0,0]Euler angles in degrees: pitch (X), yaw (Y), roll (Z)
scalevec3[0,0,0]Per-axis scale, 1 = unscaled
