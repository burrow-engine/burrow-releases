# Render options

> Generated by `make docs-gen` from the source code. Do not edit this page by hand: change the code or its doc comments and regenerate.

Set at the command line (`-shaders`, `-aa`, `-upscale`, `-render-scale`, `-rt`), in the `runtime` section of the project file, or live from the editor's View menu. Rendering is frame-domain only: none of these options changes the simulation or its `StateHash`. See [rendering.md](../rendering.md), [anti-aliasing.md](../anti-aliasing.md) and [ray-tracing.md](../ray-tracing.md).

## Anti-aliasing

`-aa off|fxaa|smaa|taa`. `off` none, `fxaa` and `smaa` single-frame filters, `taa` temporal (game only: needs motion vectors). An empty value uses the shader level's preset.

## Upscalers

`-upscale off|fsr1|fsr2|dlss|xess`. `fsr1` spatial, `fsr2` temporal, `dlss` and `xess` need vendor support and fall back with a log line. Combine with `-render-scale` (`native`, `quality`, `balanced`, `performance` or a scale 0.5..1).

## Ray tracing

`-rt off|shadows|full|sun|ao|gi|reflections`. `shadows` is sun shadows plus ambient occlusion, `full` adds global illumination and reflections, and `sun`, `ao`, `gi`, `reflections` combine with commas (`sun,reflections`). Needs hardware ray tracing support.

## Look presets

`-look natural|vivid|classic`. Colour grading applied by the tone mapper.
