# Input actions

> Generated by `make docs-gen` from the source code. Do not edit this page by hand: change the code or its doc comments and regenerate.

Scripts and the game read **actions**, never physical keys: `input_action_value` (script ABI) returns an action's value. The defaults below are the engine's `DefaultMap`; a project overrides them with the file named by `input_map` in `vox.project`, and the editor's Preferences remap the editor shortcuts the same way. A button reads 0 or 1; an axis reads a value in -1..1 (a 2D axis has x and y).
