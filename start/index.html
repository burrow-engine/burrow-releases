Play in two minutes

From the download to a running game, then to a standalone build.

  1. Step 1

    Download the Hub

    Download the Hub for your system. It is the only download: it installs the engine and the templates for you.

    Download the Hub, then run the installer or unzip it and start the Hub

    Download the Hub

  2. Step 2

    Create a project from a template

    Pick a template and make your own project from it. The Sandbox template is the quickest way to play.

    Projects, then New project, then pick a template

    Details: the Hub guide.

  3. Step 3

    Press Play, then build

    Open the project in the editor and press Play. When you like it, build a standalone game.

    burrow build -o mygame

    Details: export a game.

Prefer code?

Create the project from the command line and write your gameplay as a short Go script. Scripts compile to WebAssembly with burrow script build.

burrow new mygame -template platformer
cd mygame
burrow edit
burrowsdk.Register(burrowsdk.Script{
	OnTick: func(self burrowsdk.Entity, dt float64) {
		t, _ := burrowsdk.GetTransform(self)
		t.Rot[1] += 90 * float32(dt) // spin
		burrowsdk.SetTransform(self, t)
	}})

scripts/spin/main.go: spins whatever the script is attached to.

Good to know

  • Burrow is young and the API is v0: it may change between releases.
  • The Hub asks before it checks for updates. Until you say yes, it contacts nothing.
  • The installers are not signed yet. The download page explains the first launch on your system.
