mygame#

A multiplayer lobby and match starter. Players connect to a lobby (team, colour, ready), the host picks the map and the time limit and starts, a countdown runs, the chosen map loads, the first avatar to reach the golden pad in the middle wins, and everybody comes back to the lobby with the results.

burrow serve .                          # host: prints the join link
burrow run . -- -connect <link>         # join from another machine/CLI

Pieces:

  • runtime.lobby in vox.project: 2 to 8 players, 2 teams, 5 s countdown, two settings (map: meadow or canyon, length). See docs/lobby.md.
  • ui/lobby.ui.json: the Lobby game UI screen (player list, ready toggle, team and colour buttons, settings, host start and cancel, countdown, results with "back to lobby"). Its buttons carry lobby:* actions that the engine turns into the lobby commands; no code is needed for the input. It is the Lobby template of the game UI designer, edit it freely.
  • scripts/lobby: publishes the lobby into the screen's values, loads the chosen map when the match starts, checks the win condition and calls lobby_end_match with {"placements": {"<player id>": place}} (the convention a dedicated server forwards to a matchmaker).
  • scripts/avatars: the base multiplayer script (one avatar per connected player); see the multiplayer template.
  • levels/meadow.level, levels/canyon.level: two 64 x 64 arenas with a goal zone; add more maps by adding levels and choices of the map setting (go run ./templates/mkassets lobby_match in the Burrow checkout shows how they are built).
burrow script build   # compile scripts (burrow run / test / build do it automatically)
burrow run | burrow edit | burrow test | burrow build -o game

A dedicated server can host the matches of this project in lobby mode (docs/dedicated-server.md, "Lobby mode").

Texture licence#

The terrain uses the default block texture pack, Pixel Perfection CE (CC-BY-SA-4.0: credit the authors and keep the textures under the same licence; commercial use is allowed). burrow build prints the notice. Set "texture_pack": "none" in the runtime section of vox.project (flat colours) or build with burrow build --no-default-textures to ship without it. See THIRD_PARTY_NOTICES.md and docs/texture-packs.md.

Create it with burrow new mygame -template lobby_match.
