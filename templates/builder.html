mygame#

A creative builder on a flat world. Press 1-4 to stamp a tower, wall, pyramid or house in front of the start position (the architect script, scripts/architect/main.go). Left/right click break and place blocks by hand; Ctrl+Z / Ctrl+Shift+Z undo and redo.

burrow script build   # compile scripts/*/ to assets/scripts/*.wasm (burrow build and burrow run do it for you)
burrow run | burrow edit | burrow test | burrow build -o game

go.mod points at your Burrow checkout (replace burrow-engine => ...); re-run burrow new or edit it if you move the checkout.

Texture licence#

The terrain uses the default block texture pack, Pixel Perfection CE (CC-BY-SA-4.0: credit the authors and keep the textures under the same licence; commercial use is allowed). burrow build prints the notice. Set "texture_pack": "none" in the runtime section of vox.project (flat colours) or build with burrow build --no-default-textures to ship without it. See THIRD_PARTY_NOTICES.md and docs/texture-packs.md.

Create it with burrow new mygame -template builder.
